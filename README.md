## Retail store analysis Project 

### <u> Project Overview </u>

Analyzed sales data for the first quarter of 2025 for a retail store specializing in electronics. Developed an interactive Microsoft Power BI dashboard to visualize sales performance, identify trends, and generate actionable business insights.

![overview](https://github.com/PurbashaRay/Retail-Store-Analysis/blob/ac689665392b85faf502ad618537566c2f67ed3a/project_screenshots/overview.png)
