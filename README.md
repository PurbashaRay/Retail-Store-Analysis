## Retail store analysis Project <br>

### Project Overview

Analyzed sales data for the first quarter of 2025 for a retail store specializing in electronics. Developed an interactive Microsoft Power BI dashboard to visualize sales performance, identify trends, and generate actionable business insights.<br> <br><br>
